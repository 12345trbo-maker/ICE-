# AttendGlass HyperGlass Implementation Plan

> **For agentic workers:** تنفيذ الخطة داخل مشروع WebDev الحالي وبالتحقق بعد كل مرحلة.

**Goal:** بناء لوحة إدارة عربية لاختبار الحضور والرواتب والخصومات والجداول الأسبوعية المتغيرة بواجهة HyperGlass.

**Architecture:** واجهة React واحدة داخل `Home.tsx` تستخدم نموذج حالة محليًا قابلًا للاستبدال بعمليات tRPC لاحقًا. تفصل دوال الحساب عن العرض داخل الملف نفسه في النسخة التجريبية، وتستخدم ThemeProvider لتبديل الفاتح والداكن.

**Tech Stack:** React 19, TypeScript, Vite, Tailwind 4, lucide-react, Wouter, ThemeProvider.

**Spec:** `docs/SPEC.md`

## Global Constraints
- RTL والعربية هي اللغة الأساسية.
- لا يوجد حذف فعلي لسجل الخصم؛ الإلغاء حالة محفوظة.
- التأخير 15 دقيقة أو أكثر يبدأ بربع يوم؛ كل 15 دقيقة إضافية تضيف ربع يومًا.
- لا تُخزن بيانات حساسة أو أسرار داخل الواجهة.
- يجب توفير حالات focus وحجم لمس مناسب ودعم `prefers-reduced-motion`.
