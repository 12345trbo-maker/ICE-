# AttendGlass source archive

This archive contains the application source after the latest UI and dark-mode updates.
Generated build output, node_modules, Git metadata, preview logs, project metadata, and debug collector assets were intentionally excluded.

Install dependencies with `pnpm install`, then use `pnpm check`, `pnpm test`, and `pnpm build`.
The existing authentication and server integration source is preserved so the application remains structurally runnable.
